# Licencias de fuentes

Aquí deben vivir los archivos `OFL.txt` originales de cada familia, sin modificar:

- `LibreCaslonText-OFL.txt`
- `HankenGrotesk-OFL.txt`

La SIL Open Font License 1.1 exige que la licencia acompañe a la fuente allí donde se
distribuya. Incluirlas en el bundle de la app cumple ese requisito.
